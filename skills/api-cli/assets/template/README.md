# {{name}}

Agent-first command line for **{{title}}**: {{count}} commands, generated by
the api-cli skill from {{specs}} on {{date}}.

## Install

```bash
uv tool install --editable .
```

## Configure

| Variable | Meaning |
| --- | --- |
| `{{env}}_TOKEN` | API credential, sent the way the spec's auth scheme says (`user:password` for basic auth) |
| `{{env}}_BASE_URL` | Server URL, when it differs from the spec's |
| `{{env}}_WS_URL` | WebSocket server URL (websocket commands only) |
| `{{env}}_READ_ONLY=1` | Refuse every command except GET and websocket listening |

## Use

```bash
{{name}}                             # overview: groups, auth state, flags
{{name}} search "what you want"      # find commands by intent
{{name}} <group>                     # list a group
{{name}} <group> <action> --help     # flags, body, response fields, an example
{{name}} <group> <action> VALUE --flag value --fields a,b.c
```

Output is JSON, compact when piped. Responses over about 12 KB are cut to a
valid JSON prefix, with the full response saved to a temp file; `--fields`
keeps only the fields you name and `--raw` prints everything unmodified.
`--dry-run` shows the request without sending it, and DELETE needs `--yes`.
Websocket commands (`{{name}} ws …`) print one JSON message per line and stop
after `--count` messages or `--timeout` seconds.

## Update

`src/{{pkg}}/cli.py` and `src/{{pkg}}/commands.json` are generated. When the
API changes, re-run the api-cli skill's `scripts/build.py --rebuild .` (the
build inputs are recorded in `.api-cli.json`), then `uv run pytest`.
