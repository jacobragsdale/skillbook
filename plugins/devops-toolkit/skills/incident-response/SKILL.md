# Incident Response Runbook

Step-by-step triage workflow for production incidents.

## Steps
1. Assess blast radius and affected SLOs.
2. Establish incident channel and assign Incident Commander.
3. Use k8s-inspector and cloud-metrics MCPs to isolate root cause.
4. Record timeline events as mitigations roll out.
